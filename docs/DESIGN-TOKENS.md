# Design tokens · Gate 0

Источник реализации — app/globals.css; общие semantic CSS variables переключаются на корневом классе концепции. Это компактная основа mock, не завершённая компонентная библиотека Gate 1.

Шрифт интерфейса: Segoe UI → Arial → sans-serif; заголовки A: Georgia → Times New Roman → serif. Системные шрифты сохраняют кириллицу и работают без сетевых запросов. B: sans-serif заголовок, monospace для компактных служебных метаданных.

Шкала размеров: 10/12/14/16/18/24/32/40; мелкие 8–10px используются только для вторичных декоративных подписей. Ввод на телефоне 16px, основной заголовок 34px A / 33px B. Обложка не содержит уникальной информации: название и тип повторяются текстом ниже. Базовый ритм 4/8/12/16/20/24/32/40; gutters: 20 phone, 28 tablet, 44 desktop. Карточка A: радиус 10, поверхность 12, кнопка 7. B: радиус 3 для маркеров, разделители вместо рамок карточек.

Системные icons: lucide-react (ISC), один набор line icons. Основные действия минимум 44px; нижняя навигация 54px плюс safe area. Модальное окно — нативный dialog с фокусом, Escape и возвратом фокуса. Избранное и переключатели видов имеют aria-pressed. Ссылки открываются отдельно с noopener/noreferrer. Контраст основного и приглушённого текста проверяется отдельно; декоративные линии не используются как единственное обозначение активного состояния.

Анимации: только border-color 180ms. Reduced motion отключает переходы. Никаких градиентов, шейдеров, параллакса или animation-пакетов.

Для Gate 1 после утверждения: пересмотреть минимальную вторичную типографику по результатам реального iPhone review, выделить повторяемые числовые значения в компонентные tokens. Не расширять UI shell до утверждения.
