# Resource Hub · UX / IA · Gate 0

23 октября 2026. Новый проект; старый прототип не читался и не использовался.

## Три сценария

1. Найти: открыть каталог → ввести фрагмент названия, описания или тега → при необходимости совместить тему и тип → открыть подробности. Счётчик отражает результат фильтрации; пустая выдача предлагает сброс. Сортировка: исходный порядок подборки или название.
2. Сохранить: «Добавить» → ссылка либо документ без URL → название, тема, заметка → проверить демо-заявку. Успех означает только сформированную демонстрационную заявку pending. Никакого реального сохранения. URL не загружается; автоописание и дедупликация отсутствуют.
3. Применить: открыть карточку → увидеть описание и происхождение → перейти по одной из ссылок, отметить избранное, написать заметку или выбрать подборку. Изменения только в памяти страницы; установка/проверка ресурса не имитируются.

## Навигация

Desktop A: постоянная левая панель с каталогом, темами, подборками и избранным; быстрые ссылки на подборки; добавление в верхней панели.
Desktop B: горизонтальная навигация; рабочий индекс вместо сетки; меньше визуального шума, больше записей на экране.
Mobile: нижняя панель из четырёх действий — каталог, поиск, подборки, добавить. Темы и избранное доступны отдельными быстрыми действиями над каталогом. Поиск фокусирует поле и прокручивает его в видимую область. Меню фильтров — стандартные элементы браузера.

Главная — каталог с одной выделенной пользовательской подборкой. Темы — обзор семи широких областей и фильтруемый каталог; подборки — три демонстрационные подборки; избранное — независимый фильтр. Одна карточка может иметь несколько тем, теги и несколько URL. Тип, источник и подтверждение проверки не смешиваются.

## Честность данных

18 fixture-карточек из 27 записей реестра; число не связано с динамическим GitHub Starred. Все описания — краткие редакционные пересказы пользовательского реестра, не результаты проверки продуктов. Нет установленного/протестированного статуса. Названия и обложки не подтверждают пригодность или совместимость. Обложки — собственная типографика/CSS, не официальные бренд-логотипы и не снимки сайтов.

Council Guide: поддерживается отсутствие URL, реальный PDF не предоставлен. YouMind: две самостоятельные ссылки внутри одной карточки. Pi.Alert/MetaRadar: никаких угаданных URL. GitHub-ссылки берутся непосредственно из реестра, импорт Starred не выполняется.

## Границы mock

Нет подключения Vault, Hermes, backend, Auth, БД, очереди, импорта, cron, публикации или service worker. Локальный HTTP на loopback — средство review, не защищённый облачный сайт и не готовая iPhone PWA. Loading/error/pending доступны через явно названный демонстрационный переключатель внизу страницы. Все последующие этапы требуют отдельного утверждения.
